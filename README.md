# Convite – Encontro da Família Langa

Next.js (App Router), página única.

## Editar data e WhatsApp
Arquivo `lib/config.js`.

## Rodar local
```bash
npm install
npm run dev
```
Abre em http://localhost:3000

## Subir pro GitHub e publicar na Vercel
```bash
git init
git add .
git commit -m "convite langa"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/convite-langa.git
git push -u origin main
```
Na Vercel: **Add New → Project → importe o repositório → Deploy**.
(Framework Next.js é detectado sozinho, sem configurar nada.)
